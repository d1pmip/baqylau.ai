# 🍈 Baqylau.ai — жергілікті AI-прокторинг

**[English](README.md) | [Русский](README_RU.md) | [Қазақша](README_KK.md)**

Онлайн-емтиханды бақылаудың жергілікті жүйесі: смартфон детекциясы (YOLO),
көзқарас пен бас бағытын бақылау (MediaPipe), жұмыс ортасын қорғау
(тыйым салынған пернелер мен бөгде терезелерді бұғаттау). Барлық өңдеу оқу
орнының желісі ішінде — студенттердің деректері сыртқа шықпайды.

Кейс: Qostanai Industry Hackathon, «Жергілікті прокторинг» · Demo Day 16.10.2026.

## Қалай жұмыс істейді

- **Оқушы қосымшасы** (десктоп, PySide6): логинмен кіру, камера мұғалім
  емтиханды бастағанда ғана қосылады. Емтихан кезінде тек тест көрінеді —
  камера, тәуекел, бұзушылықтар таспасы жасырылған.
- **Мұғалімнің веб-панелі** (Flask, жеңіл): оқушы карточкалары (камера
  миниатюралары), тәуекел, негізгі бұзушылықтар, емтиханды бастау/аяқтау,
  фото/видео дәлелдері бар хабарламалар.
- **Админ** барлығын көреді: қолданушылар, аудит, барлық дәлелдер.

## Нелер анықталады

| Оқиға | Деңгей |
|---|---|
| Кадрда телефон / экранға көтеру (түсіру) | CRITICAL |
| Төмен қарау + телефон (құрылғыдан оқу) | CRITICAL |
| Бас 3 с-тан ұзақ бұрылған | HIGH |
| Көзқарас 4 с-тан ұзақ басқа жақта | HIGH |
| Екінші адам, емтихан терезесінен шығу, тыйым пернелер | HIGH/MEDIUM |
| RISK 100 | фото + ~9 с видео → хабарлама + локально (+ Drive) |

## Жылдам старт

```bash
pip install -r requirements.txt
pip install PySide6
```

**Панель (мұғалім ПК-сы):**
```bash
cd baqylau
python -m server.app   # http://<ip>:5050, алғашқы кіру: admin / admin123
```

**Оқушы:** `python main_gui.py` → кіру терезесі (сервер + логин/пароль
немесе жергілікті режим) → емтихан басталғанда тест шығады.

## Көзқарас калибровкасы (міндетті емес)

Әдепкіде өшірулі. 🎯 батырмасы — 5 нүктелі калибровка (~8 с):
жеке нөл және шектер. Калибровка кезінде тәуекел қатырылған.

## Жазбалар қайда

- Оқушы ПК-сы: `data/logs/snapshots/` (фото/видео), `events.jsonl`
- Сервер: `data/evidence/`, база `data/baqylau.db`
- Google Drive — міндетті емес (`BAQYLAU_DRIVE_FOLDER_ID` + credentials)
